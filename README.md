# Project R.E.D — Rotary Encoder Distance Measurement

Measuring distance by rotation: a wheel on a rotary encoder is rolled along a surface and the Arduino converts counted steps into distance. 2022.

![Rotary encoder distance](https://user-images.githubusercontent.com/105288469/176271868-f71cb297-a4cd-4e09-becd-5b58360f6d7f.gif)

[Watch the video](https://youtu.be/SUbPO4LzyPY)

**Hardware:** Arduino · rotary encoder — `Rotary_Encoder_Distance.ino`

The same counts-to-distance idea is what wheel odometry does on my mobile robots, e.g. [MechaBot](https://github.com/MechaMind-Labs/AMR-Mastery).
